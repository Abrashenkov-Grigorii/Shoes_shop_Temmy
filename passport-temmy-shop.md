# Паспорт проекта

## 1. Название проекта

Магазин обуви "ТЕММИ"

## 2. Проблема

У маленького магазина обуви каталог хранится на  бумаге и в Excel. Клиент не имеет возможности посмотреть товар и оформить заказ быстро и удобно. Продавец путается в своем каталоге, сложный учет наличного товара, путаница в бумагах.

## 3. Пользователи

Клиент — выбор и заказ товара.
Продавец - ведение каталога, оформление заказов.
Администратор - управление пользователями и правами.

## 4. Цель проекта

Предоставить удобный сервис для пользователей и сотрудников. Пользователь получает доступ к просмотру товаров и оформлению заказов онлайн. Продавец получает инструмент ведения каталога и учета товаров.

## 5. Метрики успеха

Время оформления заказа — < 3 минут;
Время поиска товара через систему поиска/фильтрации за < 5 кликов;
Автоматическое обновление статуса товара после продажи.

## 6. Границы (что НЕ делаем)

1. Отсутствие реальной платежной системы;
2. Отсутствие учета возможного наличия курьеров;
3. Отсутсвие аналитики продажи товаров.
4. Отсутствие слежки за пользователем, нет системы рекомендаций на основе поведения пользователя.

## 7. Риски

1. Система может сломаться после обновления — создаем заранее резервную копию проекта;
2. Долгое оформление заказа — оптимизация кода;
3. Мало фильтров для сортировки товаров — расширение функционала системы фильтров.
